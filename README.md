# objection-game

一款玩法参照《逆转裁判》(Ace Attorney) 的法庭推理冒险游戏。

## 玩法定位

- **核心循环**：调查取证 ↔ 法庭辩论
- **核心机制**：在证人证词中寻找矛盾，并用证据击破谎言
- **叙事结构**：小谜团 → 解谜 → 新展开 的高密度反转

## 技术栈

- **引擎**：Godot 4.3+（GDScript）
- **渲染**：GL Compatibility（兼容老硬件 / Web 导出）
- **分辨率**：1280×720（可缩放）

## 快速开始

### 1. 安装 Godot

```bash
brew install --cask godot           # macOS
# 或直接到 https://godotengine.org/download 下载
```

### 2. 打开工程

打开 Godot → **Import** → 选择本仓库根目录的 `project.godot`。

### 3. 运行 demo

按 `F5`（macOS：`Cmd + B`）即可运行第一话最小 demo。

### 4. 操作

| 按键 | 作用 |
|------|------|
| `↑ / ↓` | 选择证词 / 证据 |
| `E` | 打开 / 关闭证据栏 |
| `SPACE` | 在证据栏打开时**举证！** |
| `R` | 重开本话 |

### 5. 通关提示（demo 内容）

第一话只有 1 处矛盾点。证人说 *"案发当晚 9-11 点一直在房间里看综艺"*，但证据栏里有 **「电视台维修通告」**，证明当晚频道停播。选中正确证词 + 正确证据后按 `SPACE` 即可触发「异议あり！」演出。

## 项目结构

```
.
├── project.godot              # Godot 工程配置 + 自动加载
├── icon.svg                   # 项目图标
├── scenes/
│   └── main.tscn              # 入口场景（轻量挂载点）
├── scripts/
│   ├── main.gd                # 主逻辑：UI 构建 / 证词 / 举证 / 演出
│   └── systems/
│       ├── game_state.gd      # 全局状态（信任值、已收集证据）
│       └── evidence_db.gd     # 证据数据库
├── data/
│   └── cases/
│       └── case_01.gd         # 第一话案件数据
├── assets/                    # 美术 / 音效 / 字体（占位）
├── addons/                    # 第三方插件（预留给 Dialogic 等）
├── docs/                      # 设计文档
├── AGENTS.md / CLAUDE.md      # 协作规范
└── README.md
```
