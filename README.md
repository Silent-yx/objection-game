# objection-game

一款玩法参照《逆转裁判》(Ace Attorney) 的法庭推理冒险游戏。

## 玩法定位

- **核心循环**：调查取证 ↔ 法庭辩论
- **核心机制**：在证人证词中寻找矛盾，并用证据击破谎言
- **叙事结构**：小谜团 → 解谜 → 新展开 的高密度反转

## 设计参考

详细的设计调研见 `docs/design-research.md`（待补充），核心要点：

| 维度 | 设计原则 |
|------|----------|
| 创作顺序 | 谜题 → 剧情 → 角色 |
| 推理结构 | 离散的"点"组成推理"线" |
| 失败设计 | 信任值机制，错误举证扣分 |
| 角色塑造 | 谐音命名 + 强烈剪影辨识度 |
| 世界观 | 削弱真实感 / 全年龄 / 滑稽基调 |
