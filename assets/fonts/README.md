- **字体**：霞鹜文楷 Lite (LXGW WenKai Lite)
- **作者**：lxgw (https://github.com/lxgw)
- **仓库**：https://github.com/lxgw/LxgwWenKai-Lite
- **许可**：SIL Open Font License 1.1（详见 [OFL.txt](OFL.txt)）
- **风格**：基于霞鹜文楷的精简版，覆盖简体常用字 + 少量繁体，字形手写楷书风
- **大小**：~13MB（含 GB 简中字符集）

中日韩兼容，适合视觉小说/法庭推理类游戏的人文氛围。
