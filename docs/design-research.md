# 设计调研 — 《逆转裁判》游戏设计要点

> 本文档来自项目立项阶段对《逆转裁判》(Ace Attorney) 系列的设计调研，作为 objection-game 的玩法蓝本与决策参考。

---

## 1. 系列定位

由 Capcom 出品、巧舟 (Shu Takumi) 主导的「**法庭战斗 (Courtroom Battle)**」类游戏——是侦探推理 × 视觉小说 × 点击解谜的跨界融合体。

**双段式循环结构：**
- **侦探/调查部分** — 移动场景、收集证据、与人物对话
- **法庭部分** — 以"质询证人 → 找出矛盾 → 提出证据"为核心的线性推进

## 2. 核心机制

巧舟最初考虑了两个原型方案，最终选择了后者：

1. ~~"共同推理"——玩家修正侦探的推理~~
2. **"法庭辩论"——玩家作为律师指出证词与证据的矛盾** ✓

由此诞生的标志性动作：「異議あり！」+ 食指前指。

### 最小循环单元

```
听取证词 → [追问] (Press) 模糊处 → 找出矛盾 → [举证] (Present) 击破谎言
```

- **追问 (Press)**：获取证词中未明说的细节，但不一定推进剧情
- **举证 (Present)**：在错误时机/错误证据会扣"信任值"，过多则游戏失败
- 「正确证据 + 正确时机」是**唯一通关途径**——这种唯一解的设计虽然限制了自由度，但保证了推理体验的纯粹性

## 3. 巧舟的叙事设计哲学

### 3.1 创作顺序：谜题 > 剧情 > 角色

巧舟严格遵守「事件/手法 → 剧情/情感 → 角色」的递进顺序——**先想"会发生什么离奇案件、用什么诡计"，再填情节，最后塑造角色**。

这与多数日式 ADV 从"角色魅力"出发恰好相反。

### 3.2 "点-线" 推理结构（受埃勒里·奎因启发）

传统推理小说是连续的逻辑"线"，巧舟刻意采用**离散的"点"**：

- 玩家在游戏中识别一个个独立矛盾点，最终连成推理线
- **游戏的乐趣质量由这些"点"的质量与数量决定**

### 3.3 节奏公式：小谜团 → 解谜 → 新展开

为避免推理作品常见的"中段乏味"，巧舟规避了**系列谋杀**和**多案并发**：

> 小谜团 → 玩家解开 → 立刻引爆新展开 → 又出现小谜团 …

正因如此，玩家几乎每隔几分钟就能体验「**ナルホド (原来如此)**」和「**オドロキ (震惊)**」——这两个词正是主角**成步堂**和**王泥喜**名字的谐音。

### 3.4 双重身份的体验设计

让玩家**同时是"名侦探"和"震惊的读者"**：

- 既享受解谜的智力胜利
- 又能在剧情反转时被剧本震撼
- **检察官角色承担"信息隐瞒者"的功能**，因为"庭审中隐藏证据"在世界观里是合理行为

## 4. 角色设计原则

| 原则 | 做法 |
|------|------|
| **一眼记住** | 夸张的发型/服装/动作，确保剪影可辨 |
| **谐音命名** | 成步堂 (なるほど)、王泥喜 (驚き)、御剑 (みつるぎ = 剑) |
| **性格逻辑** | 每个角色的发言动机要与其性格自洽 |
| **重复登场** | 起初是开发周期限制，后来发现玩家喜爱，遂制度化（御剑因此升级为系列主役） |

## 5. 世界观三条铁律

1. **削弱真实感** — 故意虚构法律制度（三日审判制），避免现实主义对娱乐性的束缚
2. **普遍性 / 全年龄** — 不依赖时事梗，确保十年后玩起来仍不过时
3. **滑稽基调** — 即使是"找不到线索"的失败点，也安排有趣对话，让探索本身就有奖励

## 6. 机制演进史

| 作品 | 新机制 | 设计意图 |
|------|--------|----------|
| 逆转裁判 1-3 | 基础质询/举证 | 建立核心循环 |
| 逆转裁判 4 | **看穿** (微表情/小动作识别谎言) | 提供非证据型矛盾点，丰富推理维度 |
| 逆转裁判 5-6 | **心理分析锁** (从前作魂锁演化) | 把"情绪矛盾"也变成可解的谜题 |
| 逆转检察官 | **逻辑系统** (组合线索)、**反驳** | 切换到检察官视角的探索玩法 |
| 大逆转裁判 | **共同推理** (Dance of Deduction) | 实现巧舟最初被否决的方案 |

## 7. 给本项目的 5 条核心设计指南

1. **把抽象动作物理化** — "异议！"把推理过程变成 hype 时刻 → 演出必须做足
2. **失败也要有乐趣** — 查错处也写好笑的对话，错误举证不能让人感到挫败
3. **限制即美学** — 唯一解 + 信任值机制让推理纯粹而紧张
4. **结构即体验** — "小谜团循环"保证心流，避免中段沉闷
5. **角色服务于谜题** — 反推理的"角色优先"设计，反而塑造了最难忘的角色
