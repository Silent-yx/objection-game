## 一、总体世界观

| 维度 | 设定 |
|------|------|
| 原作 | 阿加莎·克里斯蒂《控方证人》（以 1953 话剧 / 1957 电影版的"庭后弑夫"加料结局为蓝本） |
| 时代 | 1950 年代·英国伦敦 |
| 地理 | 伦敦 · 律师事务所 + 中央刑事法庭 (Old Bailey 原型) |
| 玩家视角 | **资深辩护律师 Sir Wilfrid Robarts（韦菲爵士）**第一人称代入 |
| 调性 | **严肃法庭悬疑** — 没有无厘头喜剧，张力来自推理博弈与人性反转 |
| 审理形式 | 正式刑事审判，陪审团十二人，结果具法律效力（生死攸关） |
| 整体情绪基调 | 冷峻、克制、步步紧逼。**「以为赢了，其实被操纵」的智性恐惧** |
| 核心母题 | **证人可信度的反向操纵** — 不是物证诡计，而是法庭心理博弈诡计 |

### 为什么是这部作品 / 这条路线

1. **多层反转结构**是逆转裁判类机制的最高难度测试——验证 STAGES 多阶段、纯叙事页、**伪胜利转折**等机制。
2. **不可靠证人**（妻子既能定罪又能脱罪）是核心戏剧手法，本作要复现"以为赢了其实被骗"的体验。
3. 原作经 70 年舞台 / 银幕反复打磨，戏剧结构的工程价值清晰、风险可控。

> 注：原校园无厘头世界观（易南星 / USTC / 模拟法庭 / 《绿色圆圈案》）已**整体废弃**。相关美术资源（`assets/images/characters/yi_nanxing/`、`cafeteria_courtroom.png`）暂作弃用，后续按英伦法庭题材重新规划立绘与场景。

## 四、核心反转情绪曲线（玩家会经历的五段心电图）

1. **接案**（S0）：玩家以为这是个简单的"用妻子作不在场证人"案件。
2. **第一日庭审**（S1）：管家证词易碎，玩家信心增强——"这案子有得打"。
3. **第二日惊雷**（S2）：妻子反水当控方证人，且证词滴水不漏——**玩家措手不及**，跌入谷底。
4. **第三日反击**（S3）：匿名信件 → 击破妻子 → 无罪释放 → **玩家以为胜利**，肾上腺素拉满。
5. **终幕崩塌**（S4）：妻子坦白——信件是她伪造的，Leonard 真的有罪，玩家是被她利用的工具 → 紧接弑夫终局，**玩家发现自己被操纵了**。

> **每一次"以为赢了"都被下一层真相打碎**，这是本作机制验证的核心，也是改编最难的工程。

### Stage 2 · 庭审第二日·Christine 反水（TRIAL）⬜

> 玩家情绪目标：**措手不及 → 无力感**。本幕是"机制反噬"——玩家的肌肉记忆（用证据击破证词）在这里基本失效。

**剧情骨架：**
- 检方传唤 Christine Vole。她冷静、克制，作为**控方证人**指证丈夫。
- 核心杀伤证词：她推翻不在场证明——声称 Leonard 当晚 22:10 才回家，**衣袖带血**，并向她承认"我杀了她"。
- 这条"丈夫亲口认罪"的证词，是 Leonard 的死刑判决书。

**机制设计要点（难点）：**
- 与 Stage 1 相反，Christine 的证词**滴水不漏**。玩家手上的现有证据**无法击破核心证词**，或只能击破无关紧要的细枝末节。
- 目标是让玩家**亲身体验"常规手段失灵"的无力**——这是为 Stage 3 的"信件外挂"反击蓄势。
- 可保留 1 条"可击破但无济于事"的小矛盾（玩家击破后 Christine 不为所动，甚至反将一军），强化挫败感。
- 待定：是否允许玩家"卡关"一段时间后由 Mayhew 提示"我们需要新的东西"，自然过渡到 S3 的信件线索。

**过场钩子**：庭审陷入绝境后，Robarts 收到神秘女人的接触——有人愿意卖给他能扳倒 Christine 的信件。第三幕的"外挂"登场。

**待解决问题**：核心认罪证词到底"破不破"？建议设计为"本幕不可破，留到 S3 用信件破"，以制造跨幕的反击快感。详见 Stage 2-4 详设交付。

### Stage 3 · 庭审第三日·神秘信件击破 Christine（TRIAL）⬜ 🔁

> 玩家情绪目标：**伪胜利**。本幕是全篇最爽的击破序列——也是最大的陷阱。

**剧情骨架：**
- Robarts 拿到一叠信件：是 Christine 写给情人 Max 的私信，内容显示她**蓄意陷害 Leonard**、盼他被判死刑。
- 庭上交叉询问，Robarts 用信件逐条击垮 Christine 的证词与人格——陪审团认定她是个**心怀怨毒、说谎成性的女人**。
- 既然控方核心证人是骗子，Leonard 的不在场证明重新成立 → **陪审团裁定无罪 (NOT GUILTY)**。
- 落幕在最高潮：Leonard 当庭被释放，Robarts 大获全胜。**玩家以为这就是结局。**

**机制设计要点：**
- 这是标准的"高燃击破"循环：玩家用 `christine_letters`（信件）一条条戳破 Christine 的证词，节奏快、反馈强。
- **关键陷阱**：玩家击破得越爽，Stage 4 的反转越疼。引擎层面需要在 S3 营造"完整胜利"的仪式感（无罪宣判、欢呼、Robarts 的得意），**绝不能预先暗示这是假象**。

**过场钩子**：法庭清场，Robarts 独自整理卷宗，志得意满。Christine 没有离开——她走回来，要"谢谢"他。第四幕。

---

### Stage 4 · 庭审后真相 + 终幕（NARRATIVE）⬜ 🔁

> 玩家情绪目标：**崩塌 / 智性恐惧**。两层反转叠加，是全篇戏眼。

**第一层反转——信件是伪造的：**
- 空荡的法庭里，Christine 向 Robarts 揭穿：那些"揭发她说谎"的信件，**是她自己伪造的**；那个卖信给你的伦敦土腔女人，**就是她乔装的**。
- 她的逻辑：深爱丈夫的妻子作不在场证明，陪审团绝不会信；于是她**故意演成可恨的控方证人**，再亲手制造"她在撒谎"的假证据，反向操纵陪审团相信 Leonard 无罪。
- **而 Leonard 其实真的是凶手。** Robarts"赢了"官司，却成了被操纵的工具——他引以为傲的"看人本领"被彻底击碎。

**第二层反转——弑夫终局（采原作话剧 / 电影加料结局）：**
- 脱罪后的 Leonard 得意忘形，露出真面目：他要抛弃为他牺牲一切的 Christine，跟一个年轻女人远走。
- 因"一事不再理"，他已不可能再因此案受审——他自以为安全。
- Christine 悲愤交加，当庭（用作为证物的那把刀）**刺死了 Leonard**。
- Robarts 望着尸体与 Christine，决定——**这一次，他要为她辩护**。落幕。

**机制设计要点：**
- 本幕为纯叙事页 (NARRATIVE)，无击破玩法，全靠演出与台词推进情绪。
- **核心是"回收"**：把玩家在 S3 亲手用过的每一条信件证据，逐一翻转其含义，让玩家重新理解自己刚才做的每一步——"原来我亲手帮凶手脱了罪"。
- 可设计一段"证据再读"演出：S3 用过的 `christine_letters` 等证据在 S4 显示出被翻转的新注解 (detail)。

## 六、跨幕机制设计：如何实现"伪胜利转折"

这是本作区别于普通逆转裁判流程的核心，单列说明，供引擎实现参考：

1. **肌肉记忆的建立**（S1）：先用一场顺手的击破，训练玩家"用证据破证词 = 胜利"的条件反射。
2. **肌肉记忆的失效**（S2）：让常规手段对 Christine 失灵，制造无力感，使玩家"渴望新工具"。
3. **肌肉记忆的滥用**（S3）：递给玩家"信件"这个超强工具，让其酣畅击破——玩家以为自己在主持正义。
4. **肌肉记忆的反噬**（S4）：揭示"击破"本身就是陷阱，玩家越熟练越是帮凶。
5. **证据语义翻转**：同一份证据 (`christine_letters`) 在 S3 与 S4 含义相反——引擎需支持"按阶段切换证据 detail 注解"或等效演出。

> 实现（已落地）：不新增 Stage 类型；S2 用 `trial_mode:"NARRATIVE_TRIAL"` 旁路（出示即反杀 + 自动认输）；证据翻转用 `detail_after` 数据驱动 + S4 `inspect_evidence` 定向再读。详见 [script-stage2-4.md](script-stage2-4.md) 与 `scripts/main.gd`。
