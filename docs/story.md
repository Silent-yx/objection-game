## 总体世界观

| 维度 | 设定 |
|------|------|
| 时代 | 当代 (2026 前后) |
| 地理 | 中国合肥，中国科学技术大学 (USTC) 东区校园 |
| 玩家视角 | 主角易南星（大一新生）第一人称代入 |
| 调性 | **校园无厘头悬疑** — 案件改编自真实校园轶事，放大荒诞感。不死人/不犯罪，但每场都关乎名誉 / 处分 / 信任 |
| 审理形式 | **学生自发的「模拟法庭」** — 非正式仲裁，结果不具法律效力但影响校内声誉 |
| 整体情绪基调 | 紧张感来自推理本身、笑点来自现实细节。**周星驰式喜剧 + 逆转裁判结构** |
| 素材原则 | **每个案件至少有一个核心情节来自真实事件**，再用模拟法庭框架夸张化 |

### 为什么是「模拟法庭」？

校园里没有真法庭——但当事件涉及"清白与名誉"，学生群体会自发组织一种类似的对峙场合。第一话设定为：
- 食堂顾客围观下的临时仲裁
- 由"裁判方"（学长 / 学生干部 / 公正方）主持
- 证人轮流陈述，主角作为"被告"自我辩护
- 围观学生构成"陪审团" — 信任值机制由他们决定

## 第一话：《绿色圆圈案》

> 改编自 USTC 真实事件「绿色圆圈」— 少年班学生不识辣椒，发帖吐槽食堂菜里有"绿色圆圈"。

### 世界观校正

**USTC 没有法学系。** 本作所有"懂法律"的角色都是**自学 / 学生组织出身 / 跨专业兴趣**。一群理工科学生用半桶水的法律知识办起了模拟法庭——这本身就是无厘头的核心引擎。

### 案件梗概

- **时间**：开学第三周的周二午餐高峰（约 12:15）
- **地点**：USTC 东区学生第二食堂一楼
- **主角立场**：被指控为"投放绿色小怪兽"的犯人，需自我辩护

### 案件性质（核心叙事手法）

**"严肃推理结构 × 荒诞被害事件" — 用『死亡案件』的庭审格式包装『被辣到』这种小事。**

- 剧中人物**全程当真**：少年班同学痛哭、检察师兄要"讨回公道"、保安严肃维持秩序
- **玩家视角**全程觉得荒谬：你们这是因为一颗辣椒吗？
- 这种**严肃与荒诞的张力**就是本案最核心的喜剧引擎

具体表现手法（夸张化"被害"）：
- 受害者被辣到 **失声 / 晕厥** —— 对照传统推理中"被害者已死无法作证"
- 因为受害者无法亲自陈述，**检方只能转述他的话**（"据他事前微信说……"）
- 这就给玩家创造了挑出"转述误差"的天然空间

### 受害对象 / 受害事件
- **受害者**：少年班 14 岁学弟 **白小研**（暂定姓名）
  - 设定：智商超群、说话奶声奶气、生活白痴
  - 关键梗词：管辣椒叫**"绿色圆圈"** / **"绿色小怪兽"**
- **受害事件**：在食堂点了"宫保鸡丁"，被干辣椒辣到**当场晕厥被抬走**
- **戏剧结构后果**：**白小研全程不在庭审现场**
  - 检察方只能**转述**他事前/事后的说法
  - 玩家的目标 = 从这些**二手陈述**里挑出漏洞
  - 类比传统推理：受害者"已死"无法对质 → 这里受害者"晕了"无法到庭

### 出场角色

| 角色 | 设定 |
|------|------|
| **检察师兄：赵为**（少年班大三）| • USTC **少年班大三**学生，与受害者白小研同属少年班（师兄弟），强势维护学弟的根本动机<br>• 物理 / 数学专业（非法学），**业余自学法律**，校内"学生模拟法庭联合会"主要发起人<br>• 御剑型：冷静理性、言辞尖锐、扶眼镜、永远夹着一本《刑事诉讼法》<br>• **招牌台词**：「**少废话，你 GPA 多少**」—— 用学术成绩当武器质问对方<br>• 战略：法律术语 + GPA 鄙视链 双管齐下<br>• **结尾彩蛋**：他其实**早就发现真相**，但想看新生易南星能不能自己证明——潜在的"暗中欣赏者"，第二话伏笔 |

| **证人 2：钱方达** | 白小研的少年班同班同学，案发时同桌吃饭<br>• 戴厚框眼镜、紧张兮兮、忠诚但不靠谱<br>• 立场偏向白小研，但**记忆有偏差**（他当时在背元素周期表，没好好观察） |

### 「少废话，你 GPA 多少」台词节点

赵为这句招牌台词在第一话中**至少出现 2 次**：

1. **开庭第一次发力时**（亮相）—— 质问易南星：「**少废话，你 GPA 多少？**」
   - 易南星：「我、我才大一刚开学……还没 GPA……」（汗滴 nervous 表情）
   - 赵为：「连 GPA 都没有还敢上庭辩护？」
2. **关键证词被击破前的最后挣扎** —— 再次祭出 GPA 台词试图压制
   - 这次易南星不为所动（成长转折点）：「GPA 是衡量学习能力的指标，不是判断事实的标准。」
   - 赵为愣了一下、扶眼镜——这是他第一次表情松动

### 调查阶段（本话不启用独立调查）

**第一话直接从庭审开始**。但庭审推进过程中：
- 起手 2 件证据（菜单、监控）已在物品栏
- 庭审推进时**自动追加**新证据（小票 / 小红书 / 干辣椒标本）
- 玩家可在证据栏内**选中证据 + 按 `D` 键**调查"深度详情"，发现关键暗示

调查阶段作为独立机制留到**第二话**才引入。

### 法庭对峙流程

1. **开庭** — 主持人学长用饭勺敲桌：「模拟法庭，现在开庭！」
2. **检方陈述** — 赵为用法律术语包装"投毒罪嫌疑"，祭出第一次 GPA 台词
3. **证词 1 出示** — 赵为转述「他点的是不辣的菜」 → 玩家用 `lunch_receipt` 击破
4. **证词 2 出示** — 钱方达 "我亲眼看到他手伸进盘子" → 玩家用 `seat_photo` 击破
5. **证词 3 出示** — 赵为转述「绿色圆圈是人为投放」 → 玩家用 `cafeteria_menu` 击破，**赵为第一次表情松动**
6. **证词 4（可选）** — 钱方达 "他从来没吃过那种东西" → 玩家用 `redbook_post` 揭露白小研有"前科"
7. **真相阶段** — 主持人宣判易南星无罪
8. **彩蛋** — 赵为合上书离开前对易南星说一句：「……新生，记住今天」（第二话钩子）

### 矛盾点设计

| # | 证词来源 | 证词 | 矛盾证据 | 击破后揭露 |
|---|---|---|---|---|
| 1 | 赵为转述 | 「被害人事前一再强调他点的是『不辣的菜』」 | `lunch_receipt` | 「……（赵为停顿）小票上确实写着『中辣』。但被告，这只能说明……」 |
| 2 | 钱方达 | 「我亲眼看到这位同学从小研旁边经过时，**手伸进了他的餐盘**！」 | `seat_photo` | 「啊？……可能、可能是我看错了？我那时候在背元素周期表……」 |
| 3 | 赵为转述 | 「被害人坚持说菜里的『绿色圆圈』是人为投放的、不该出现在菜里」 | `cafeteria_menu` 或 `chili_specimen` | 「……『含干辣椒』。这是宫保鸡丁的标准配料。」 |
| 4 | 钱方达 | 「小研从来没吃过那种东西，肯定不是他自己点的！」 | `redbook_post` | 「等等，这是上周……小研同学**之前就遇到过『绿色小怪兽』**？」 |

> 玩家**至少击破 #1 #2 #3 三条**才能推进真相阶段；#4 是"超额揭示"触发隐藏剧情。

### 关键证据清单

| ID | 名称 | description（一眼可见） | detail（按 D 调查后看到） | 出场时机 |
|---|---|---|---|---|
| `cafeteria_menu` | 宫保鸡丁菜单照 | 档口公示牌：「宫保鸡丁 ¥8」 | 标注「**中辣 · 含干辣椒**」 | 开局已有 |
| `seat_photo` | 排队监控照 | 易南星端着自己餐盘从白小研旁路过 | **双手都端着自己的盘子**，没有空手伸向受害者方向的动作 | 开局已有 |
| `lunch_receipt` | 白小研的饭票小票 | 12:14:33 出单 | 明确写着「**宫保鸡丁 中辣 ¥8**」 | 证词 1 击破或周阿姨发言后追加 |
| `redbook_post` | 白小研一周前的小红书 | 截图标题：「南方菜好神奇 😭」 | 正文写：「**每次都吃到绿色小怪兽**」 → 一周前就遇到过 | 询问钱方达后追加 |
| `chili_specimen` | 干辣椒标本 | 一颗完整干辣椒 | 周阿姨："这就是宫保鸡丁里的，**整袋整袋买来的**" | 证词 3 阶段周阿姨递交 |

### 结局

- **直接结局**：易南星无罪释放，围观学生鼓掌起哄，信任值满血
- **白小研后续**：在医务室醒来，听完原委红了脸，主动来道歉——承认自己不认识辣椒。**变身易南星的"理论搭档"**，第二话起以协助方姿态登场
- **彩蛋**：赵为留下「……新生，记住今天」便扶眼镜离去
- **主角成长**：易南星从"被动辩护"成长到能反驳 GPA 鄙视，下一话开始能主动发起调查

### 伏笔 / 后续衔接

- **赵为的"放水"**：他其实早看穿真相，借审判试探易南星的逻辑能力 → 第二话以"协助 / 暗中支援"姿态再登场
- **白小研的成长方向**：从"生活白痴神童"逐步学会基础生活常识，成为主角的反差搭档
- **模拟法庭联合会**：赵为作为发起人，意味着后续案件都可能在他的"地盘"上进行

## 附录：机制验证版（《控方证人》改编）

> 此版本**仅用于游戏机制验证**，**不会公开发布**。所有对话**全部原创改编**，仅保留戏剧反转节奏，不复用原作台词。
> 原作《控方证人》(1953 话剧/1957 电影) 著作权属阿加莎·克里斯蒂遗产管理人 + 制片方所有。后续正式作品**必须替换为完全原创剧本**。

### 为什么用这部作品做验证

1. **多层反转结构**是逆转裁判类游戏机制的最高难度测试——可以验证 STAGES 多阶段、纯叙事页、伪胜利转折等机制
2. **不可靠证人**（妻子既是辩方又当控方）是核心戏剧手法，本作希望复现这种"以为赢了其实被骗"的体验
3. 原作戏剧结构经过 70 年舞台 / 银幕 / 剧院反复验证，工程价值清晰

### 改编 Stage 计划（共 5 幕，约 60-75 分钟）

| Stage | 类型 | 场景 | 已实现 |
|---|---|---|---|
| 0 | NARRATIVE | 律师事务所·初见 — Robarts 接案、Leonard 自述、遗嘱意外 | ✅ |
| 1 | TRIAL | 庭审第一日 — 管家 Janet 的 5 条证词 | ✅ |
| 2 | TRIAL | 庭审第二日 — Christine 反水（首次大反转） | 待批次 B |
| 3 | TRIAL | 庭审第三日 — 神秘信件击破 Christine + 伪胜利 | 待批次 C |
| 4 | NARRATIVE | 庭审后真相 — Christine 坦白 + 终极反转 | 待批次 C |

### 角色（改编版）

- **Sir Wilfrid Robarts** — 玩家视角，资深辩护律师，心脏病初愈
- **Leonard Vole** — 被告，26 岁退伍青年，外表无辜
- **Romaine / Christine Vole** — 被告之妻，外籍，神秘冷漠（第三幕反转关键）
- **Janet MacKenzie** — 受害者管家，21 年老仆，听力受损（第一幕证人）
- **Mayhew** — Robarts 的事务所助理
- **Mr. Myers** — 检方代理人
- **Justice Wainwright** — 主审法官
- **Emily French** — 受害者（不在场），富婆，82 岁，喜欢年轻男子陪伴

### 核心戏剧反转节奏（玩家会经历的情绪曲线）

1. 接案：玩家以为这是个简单的"用妻子作不在场证人"案件
2. 第一幕庭审：管家证词易碎，玩家信心增强
3. 第二幕惊雷：妻子反水当控方证人 — **玩家措手不及**
4. 第三幕反击：匿名信件 → 击破妻子 → **玩家以为胜利**
5. 终幕崩塌：妻子坦白真相 — **玩家发现自己被操纵了**

每一次"以为赢了"都被下一层真相打碎，这是机制验证的核心。
